# IPPITSU

一本の線を、短い譜面にするブラウザ小品です。

先に四つの音階からひとつを選びます。線の横方向は八つの拍、縦方向は選んだ音階の高さです。折れや戻り、描く速さが、音の言い方へ反映されます。

一筆目を残して二筆目を描くと、前の線は半拍遅れて返事をします。音は初期ミュートで、「音を入れる」を押した時だけ有効になります。線も音も保存しません。

## 開発

```bash
npm install
npm run dev
npm run lint
npm test
npm run build
```

描きにくいときは、円・稲妻・波から始められます。OS の動きを減らす設定も反映します。
